# Дипломный проект: Автоматизация тестирования API сервиса Stellar Burgers

Данный проект содержит автотесты для проверки ключевых эндпоинтов API космической бургерной **Stellar Burgers**. Тесты написаны на языке **Python** с использованием фреймворка **Pytest** и библиотеки **Requests**. Для генерации отчетов настроен **Allure Report**.

## 🛠️ Стек технологий
* **Python 3.x** — язык программирования.
* **Pytest** — фреймворк для написания и запуска тестов.
* **Requests** — библиотека для отправки HTTP-запросов к API.
* **Faker** — генерация случайных и уникальных данных пользователей.
* **Allure Framework** — визуализация результатов тестирования.

---

## 📋 Покрытый функционал (Тест-кейсы)

В соответствии с техническим заданием диплома, автотестами покрыты следующие сценарии:

1. **Создание пользователя (`POST /api/auth/register`):**
   * Создание уникального пользователя.
   * Ошибка при создании пользователя, который уже зарегистрирован.
   * Ошибка при создании пользователя, если не заполнено одно из обязательных полей.
2. **Логин пользователя (`POST /api/auth/login`):**
   * Успешный вход под существующим пользователем.
   * Ошибка при входе с неверным логином и паролем.
3. **Создание заказа (`POST /api/orders`):**
   * Успешное создание заказа авторизованным пользователем.
   * Успешное создание заказа неавторизованным пользователем.
   * Ошибка при создании заказа без ингредиентов.
   * Ошибка при создании заказа с неверным хешем ингредиентов.

## 🚀 Инструкция по запуску проекта

### 1. Клонирование репозитория
```bash
git clone <ссылка_на_твой_репозиторий>
cd <название_папки_проекта>
```

### 2. Настройка виртуального окружения
```bash
# Создание окружения
python -m venv venv

# Активация окружения (Windows)
venv\Scripts\activate

# Активация окружения (macOS/Linux)
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск автотестов
Чтобы запустить тесты и собрать данные для отчета Allure, выполните:
```bash
pytest --alluredir=allure-results
```

### 5. Просмотр отчета Allure (требуется установленный Allure CLI)
```bash
allure serve allure-results
```
